# Software availability statement

GumOptic-Consensus is implemented as an R Shiny application. Version 1.0.0 of the publication package contains the reader-facing Shiny application, the 23-descriptor image-feature extractor, the portable 400-tree Random Forest node table, robust-scaling parameters, species-centroid reference, model metadata, model-building/export script, and image-level cross-validation summaries. The exact release accompanying the manuscript should be deposited at **[PUBLIC GITHUB REPOSITORY URL]** and archived as an immutable release at **[ARCHIVE DOI, e.g. Zenodo DOI]**. The software is distributed under the MIT License.

The reader-facing application performs inference without requiring the original training-image archives. The reference model was developed from 710 labelled photographs representing 13 woody plant species. The original source photographs are not included in this software release and should be described in the article according to their actual redistribution status. The repository includes the portable trained-model files, species-level cross-validation summary, fused-model confusion matrix, and model-building script. The application reports Random Forest support, robust-scaled centroid similarity and distance, a fixed 0.70:0.30 RF-centroid fusion ranking score, ranked candidate species, and a downloadable 23-feature optical profile. The fusion score is a ranking score rather than a calibrated posterior probability, and the application is intended for closed-set screening rather than definitive botanical authentication or validated open-set recognition.
